# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in our repository](https://github.com/changesets/changesets)

We have a quick list of common questions to get you started!

## `\.changeset`

We use this folder to keep track of changes as we work in the repository.

## `pnpm changeset`

Run this command when you have made a change that should be included in the next release. It will ask you a series of questions and generate a changeset file.

## `pnpm version-packages`

Run this command to consume all the changesets and update the package versions and changelogs.

## `pnpm release`

Run this command to publish all the packages to NPM.
